This is a public demo dashboard. The numbers above are synthetic — generated from a fixed seed by the project's demo kit, not from anyone's real finances. In a real client install, this dashboard renders on the laptop that produced it. If the user chooses to share with their advisor, the published copy lives behind a passcode and contains the categorized transactions and CSV exports — but never the original source files (bank statements, paystubs, tax documents).
