AI is a medium, not a tool

A tool has known failure modes you can diagnose. A medium reshapes how people work and think. AI sits in the second category — probabilistic, generative, and with failure patterns that shift on every model update.

Each person reasons through their own AI; AI also runs inside the services they share.

Adoption today

  • ChatGPT: ~900M weekly users.
  • OpenAI Codex (their AI that builds software): ~2M weekly users.

The tension triangle

Three forces every team adopting AI has to balance:

  • Velocity — how fast you can ship and iterate.
  • Assurance — how much structure verifies the output before it matters.
  • Legibility — how well you can still see what's happening.

Push any one too hard and the other two collapse. This project sits on the velocity end — disposable apps live here on purpose. Fast, low-stakes, easy to throw away.

PASSPORT TO WEALTH · CLARITY APP

Success vs. failure patterns

Patterns that work

  • Play first, plan second — let exploration run, then formalize what stuck.
  • Harvest from practice — wait for a workflow to prove itself before standardizing.
  • Sandbox the experiment — keep throwaway separate from production.

Patterns that fail

  • Premature standardization — picking the official workflow that will change in three months.
  • Disorientation — shipping faster than the team can keep up.
  • Blast radius — letting agents act on things they shouldn't.

Installing Claude Code

1 slide + live action · ~8 min

PASSPORT TO WEALTH · CLARITY APP

Live install on Windows

  1. Open PowerShell — Start menu → type "PowerShell" → Enter. The PS C:\> prompt is the right one (not Command Prompt).
  2. Run the official installer: 
    irm https://claude.ai/install.ps1 | iex
  3. Restart PowerShell — fresh window. Otherwise claude won't be on PATH.
  4. Verify: 
    claude --version
  5. Authenticate: run claude, sign in via browser, back to the terminal.

Claude Code 101

4 slides · ~12 min

PASSPORT TO WEALTH · CLARITY APP

1. The agentic loop

Claude works in a loop:

  1. Gathers context — reads your files.
  2. Proposes an action — in plain English.
  3. Does the action — after you say yes (or you pre-approved automatic changes).
  4. Verifies — checks it worked.
PASSPORT TO WEALTH · CLARITY APP

2. Permission modes — Shift+Tab

Three modes, toggled by pressing Shift+Tab:

  • Default — Claude asks before each file change.
  • Plan mode — Claude can read everything, but cannot change anything.
  • Auto-accept — Claude works without asking. Skip this for now.
PASSPORT TO WEALTH · CLARITY APP

3. Plan mode on a vague request

Live demo (4 min): in plan mode, ask:

"Add a section to the dashboard that shows my top five spending categories with a small description of each."

Claude reads files, proposes a plan, asks for approval. Don't approve yet.

Edit the plan in plain English:

"Actually, top three categories — not five."

Claude updates the plan. Then approve.

4. Three keystrokes that matter

KeyWhat it does

Esc EscRewind — undo both the conversation and the file changes since your last message.
